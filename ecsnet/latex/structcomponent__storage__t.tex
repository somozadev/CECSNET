\doxysubsection{Detailed Description}
Storage container for a single component type. Each registered component type gets its own storage structure. It contains\+: 


\begin{DoxyItemize}
\item The descriptor describing the component type (size, name, serialization functions).
\item A contiguous block of memory for all entities\textquotesingle{} data of this component type.
\item Arrays to track which entities have this component ({\ttfamily used}) and which ones have been modified ({\ttfamily is\+\_\+dirty}). 
\end{DoxyItemize}
