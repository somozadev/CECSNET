\doxysubsection{Detailed Description}
Internal structure representing the ECS world state. This holds\+: 


\begin{DoxyItemize}
\item All entity metadata.
\item Component storage for every registered component type.
\item A list of registered systems and the total count.
\item The number of registered components.
\end{DoxyItemize}

This is the core ECS structure passed to all internal and public ECS functions.
